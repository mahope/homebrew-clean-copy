# homebrew-clean-copy

Homebrew tap for [clean-copy](https://github.com/mahope/clean-copy-cli) — copy/paste text as clean Markdown from your terminal.

## Install

```bash
brew tap mahope/clean-copy
brew install clean-copy
```
